# Security Policy

AegisMesh is a defensive simulation project. Do not use it to target systems without authorization.

## Public-lab boundaries

- Synthetic scenarios only.
- No malware, exploit execution, credential theft, persistence, scanning, or autonomous containment.
- No live cloud or SaaS credentials.
- No arbitrary shell or network tools exposed to agents.
- Consequential actions are represented as approval-required requests, not executed operations.

## Reporting

If you find a security issue in the code or repository configuration, report it privately through the repository's security reporting channel when available. Do not include real secrets, customer data, or exploit payloads in public issues.
